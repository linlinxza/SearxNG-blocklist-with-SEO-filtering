# SearxNG-blocklist-with-SEO-filtering

Filters a lot of the crap I've come across in search results. Over time, I've kept on adding to it. Now I feel like sharing it. There may be some false positives with how my filtering is with the odd broad term. But so far, I'm happy with it. It's made me realize just how irrelevant search engines have become; not unless you have something very specific to search up.

I limit the pages to just one page of search results. Mainly because search results become trash by page two.

I keep the blacklist and the settings file separate from each other like so (with both files in the same folder):

hostnames:
  remove: 'blocklist.yml'

This is tailored to my needs. Edit as you like for yourself.
